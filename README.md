# My Portfolio

A responsive personal portfolio website for Mohammed Masud (Okasha) — Full-stack web developer & app designer.

🔗 **Live site:** https://okasha-fulldev.github.io/my-portfolio/

## Pages

- **Home** — introduction and CV download
- **About**
- **Services**
- **Skills**
- **Contact**

## Features

- Fully responsive (mobile, tablet, desktop) with a mobile navigation drawer
- Pure HTML, CSS and JavaScript — no build step

## Run locally

Open `index.html` in your browser.

## Hosting

Deployed with GitHub Pages from the `main` branch.
